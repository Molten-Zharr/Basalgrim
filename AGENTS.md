# Basalgrim

Basalgrim is a native Linux GUI/TUI file manager for Molten-Zharr.

- Rust 2024; Ratatui is the single renderer for GUI and TUI. GUI uses eframe/egui_ratatui/soft_ratatui; TUI uses Crossterm. Keep GUI dependencies behind `guitui` and terminal dependencies behind `tui`.
- Share behavior through `App`, `Action`, and `Input`. Register hit regions in the same renderer that draws their controls. Don't duplicate filesystem logic in either frontend.
- Every file command must be reachable with the mouse, including compact layouts. Keep the shared Actions menu, secondary clicks, independent mark controls and modal dismissal without click-through. Native GUI clipboard shortcuts must preserve raw keys and exact modifiers before egui's clipboard interception, including an empty OS clipboard; verify the real GUI with scripts/smoke_gui.py when changing input.
- Right-click menus are contextual: one entry, a marked group, or the current directory background. Show only applicable available commands; keep global commands in Actions/Shift+F10. Each command row owns its hover hit region even when disabled; menu background and outside-dismiss regions must never receive hover tint.
- Hover is separate from selection and keyboard focus. Resolve the topmost current hit region after modal rendering; tint only its background and preserve selected backgrounds. Pointer movement must not navigate, change selection, mark files, or request previews. Clear hover when the pointer leaves or the terminal loses focus.
- Wheel input scrolls the hovered file pane's viewport without changing selection, marks, active pane or preview. Keep manual scrolling independent of renderer cursor-following; keyboard navigation reveals focus again. Preserve a manual viewport across refreshes and bound offsets after resize/filtering. Verify GUI and PTY wheel events, not only shared selection actions.
- Rubber-band selection uses explicit press/drag/release inputs, separate from hover, and renderer-owned file viewports/hit geometry. Keep it within the originating pane; Ctrl adds to the original set, Esc/focus loss restores it. Cancel stale gestures on directory requests, tab changes and layout changes. An explicit empty selection must not fall back to the keyboard-focused file. Draw the GUI outline after SVG composition and verify real GUI and PTY drags.
- Icon geometry and classification are shared by GUI/TUI. Use embedded SVGs colored by the current Palette, and honor the persisted Images/Symbols preference. Probe terminal graphics before the input loop with a bounded synchronous read; never leave a stdin-reading probe thread or change tmux settings. Unsupported terminals use symbols. Keep image work off the TUI loop, validate asynchronous cache generations/request IDs, and prevent images from covering modals or accumulating in the cached GUI raster.
- Use `assets/brand/molten-zharr.json` for palette roles and the default brand colors. Appearance has four Almavorn palettes plus per-theme color overrides; build a Palette from the current Settings, without global mutable theme state. Fira Code and DejaVu Sans Mono licenses are bundled; terminal fonts remain terminal-controlled.
- Settings share one Ratatui screen. Persist all command bindings, match normalized modifiers exactly, and capture a new shortcut before dispatching actions. Keep navigation keys reserved, reject conflicts, and derive command/help labels from the active bindings. Keep the legacy JSON font_size key readable through flattened Appearance.
- Read directories, previews, and operations in workers. Validate request IDs before accepting asynchronous results.
- Session startup is shared by GUI/TUI. Keep App::new deterministic for tests/previews; only startup attaches storage. Restore both panes and active tabs only without an explicit CLI directory; --no-session reads/writes no session. Validate bounded/versioned data and preserve malformed files without autosaving over them. Store raw Unix paths losslessly, keep unavailable directories as error tabs, and exclude selection, filters, clipboard and operations. Write atomically through a coalescing worker with current-generation results, cancel pending writes when disabled, and flush the final snapshot on normal close. Isolate XDG_STATE_HOME in smoke tests.
- Watch all open tab directories outside the UI thread. Coalesce event bursts with a bounded delay, cancel obsolete scans between entries, rearm replaced/missing directories, and drop watches on shutdown. Background refresh preserves path-based focus, marks, filter, sort and viewport; keep the old frame while reading and defer applying results during dialogs, marquee gestures and operations. Verify external changes in native GUI and PTY without refresh input.
- Never overwrite existing destinations implicitly. Keep no-replace publication, staged copies, non-following symlink copies, rejection of recursive destinations, and accurate partial-operation reports.
- Normal GUI/TUI startup attaches the shared SQLite journal; App::new and the plain filesystem API remain deterministic for tests/previews. Use the operation worker for all database I/O. Commit item/step intents before mutating user data and recheck cancellation after a potentially blocking commit. A journal failure before mutation blocks it; a recording failure afterward must preserve exact completed/cut counts and never remove published results. Recovery renames ignore cancellation and recording failures. Record raw paths, no-follow identities, actual Keep Both destinations, staging/claim paths and blocked inverse plans when evidence or old data is missing. Recover dead owners through independent file locks, never infer completion or replay filesystem actions. Drain the operation/journal worker at shutdown; external application waits use a separate worker.
- Conflict decisions share one GUI/TUI modal with mouse controls at minimum size. Wait only in the worker, check cancellation and operation/request IDs, and scope batch choices to one operation. Keep Both is the default; skip is distinct from completion. Revalidate an approved target before replacing it, retain the old object until publication, and restore without replacement on failure. Never auto-delete a backup of user data; report recovery paths and count a published item before backup cleanup errors.
- Other-pane transfers capture the selected sources and the opposite active tab's directory at dispatch; require an enabled, resolved opposite pane. Duplicate uses the same worker copy engine with automatic Keep Both naming. Keep the existing clipboard and shortcut assignments; only completed moves prune matching cut paths. Expose these commands through contextual and compact shared menus.
- Cross-filesystem moves fall back only on EXDEV. Verify bounded copies and source identity/content before publication and deletion; fsync the destination before removing originals. Reject nested mounts. Claim source data privately before cleanup, never put claimed user data under an auto-deleting TempDir, and restore without replacement on failure. Preserve published copies and expose remaining-source recovery paths. Count only fully removed sources as completed moves; retain unfinished cut paths. Once source deletion starts, finish the item before honoring cancellation.
- Operation cancellation checks occur during preparation, between copy writes and before no-replace publication. Cleanup cannot be cancelled; count an atomic step once it succeeds even if cancellation races it. Coalesce worker progress, validate operation IDs, and remove only actually completed cut sources from the clipboard. Keep existing shortcut assignments when migrating new commands.
- Keep README minimal: purpose, short description, current screenshot and a documentation link. Detailed instructions belong in docs/USAGE.md; refresh committed screenshots when the UI changes.
- Trash uses `gio trash` without permanent-delete fallback. Tests must isolate HOME and XDG data in the same filesystem because GLib compares source and HOME devices when choosing trash; never empty the user's trash.
- Verify with `cargo fmt --check`, strict all-feature Clippy, all-feature tests, and TUI-only tests. `cargo run --example preview` renders the real shared interface without a display.
- Keep generated `target/` and `graphify-out/` local. The shared Harness stays at its permanent path. Do not install repository hooks unless the user explicitly connects the repository.
