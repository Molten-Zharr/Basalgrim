# Этапы разработки

## 0.1 — рабочее ядро

Реализовано: общий Rust/Ratatui-интерфейс с оконным egui и терминальным Crossterm; палитра Molten-Zharr и Fira Code; навигация, сетка/список, вкладки, две панели, текстовый предпросмотр, фильтр, выбор, внутренний файловый буфер, создание, переименование, копирование, перемещение внутри файловой системы и системная корзина. Это первый срез с фокусом на Linux, а не законченный выпуск.

Добавлен экран настроек по модели Almavorn: темы Molten-Zharr, Classic Amber, Classic Violet и Light, цвета каждой темы, Fira Code / Fira Code Bold / DejaVu Sans Mono, размер и геометрия; переназначение и сброс клавиш, проверка конфликтов и актуальные подсказки. Настройки применяются сразу, JSON сохраняется атомарно с поддержкой прежнего font_size. Каталог пользовательских пресетов, профили и обмен палитрами остаются возможным продолжением.

Добавлены графические SVG-иконки папок и типов файлов в сетке и списке с цветами текущей темы и учётом масштаба GUI. TUI проверяет графические возможности терминала и использует изображения при поддержке Kitty/Sixel/iTerm2, иначе — символы. В настройках можно выбрать символьные иконки независимо от доступности графики. Миниатюры содержимого файлов остаются отдельным этапом предпросмотра.

## 0.2 — операции и ежедневная работа

1. **Готово:** прогресс в байтах и элементах, отмена копирования в безопасных точках, очистка staging и общий экран операций GUI/TUI с историей текущего запуска. Завершённые элементы перечисляются явно; отмена атомарных операций останавливает пакет между элементами.
2. Перемещение между файловыми системами: copy → проверка результата → удаление исходника с обработкой частичных ошибок. Сначала определить гарантии при параллельном изменении исходника.
3. Обновление каталогов по событиям файловой системы, объединение повторных запросов, отмена устаревших сканирований.
4. **Готово:** общее меню действий по правой кнопке, через панель и Shift+F10; мышью доступны файловые команды, отметки, вкладки и операции в том числе в узком окне. Дальше — редактор текста с курсором и выделением; вставка системного текста уже работает.
5. Избранные места и каталоги XDG, восстановление вкладок, действия копирования/перемещения в соседнюю панель, регрессионная проверка TTY и раскладок клавиатуры.

## 0.3 — история и предпросмотр

1. Журнал операций с устойчивыми идентификаторами и хранением в SQLite. Прежде чем добавить Ctrl+Z, определить undo для copy/move/rename/trash, проверки конфликтов и поведение после перезапуска.
2. Изображения: единая модель превью; текстура в GUITUI, протоколы терминала или упрощённое изображение в TUI. Ограничить размер, декодирование и кэш.
3. Подсветка кода, поиск по подпапкам и отменяемая очередь поиска.
4. Просмотр и восстановление корзины из приложения.

## 0.4 — расширенные инструменты

Встроенный терминал через PTY, архивы, подключаемые накопители и сетевые расположения, перетаскивание, массовое переименование. Каждый инструмент должен предоставлять общие действия и состояние для GUITUI и TUI.

Название приложения — **Basalgrim**. Имя Rust-пакета и бинарника — `basalgrim`, терминального бинарника — `basalgrim-tui`.
