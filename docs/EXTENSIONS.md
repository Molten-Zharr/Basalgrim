# Расширения

Откройте **Действия → Расширения**, **Ctrl+Alt+X** или **Настройки → Система → Расширения**. Клавишу можно переназначить.

1. Нажмите **Установить** и укажите папку пакета. Если выделена папка, её адрес уже подставлен.
2. Выберите установленное расширение и нажмите **Включить**. Установка сама по себе код не запускает.
3. На вкладке **Команды** появятся действия для текущего выбора. Один щелчок выбирает команду, двойной щелчок, Enter или **Выполнить** запускает её.

В контекстном меню файла, выделенной группы или свободного места есть **Команды расширений…**, когда для этого контекста доступны команды. Предпросмотр включённого расширения используется автоматически для заявленных расширений файлов. При ошибке остаётся встроенный предпросмотр с пояснением.

**Выключить** отключает команды, предпросмотр и события. **Удалить** удаляет установленную копию; исходная папка пакета сохраняется. Включение сохраняется между запусками GUI/TUI. **Обновить / F5** перечитывает каталог. Изменённый после включения пакет отключается до проверки и повторного включения. Новую версию устанавливают после удаления прежней.

Расширение — исполняемая программа с правами текущего пользователя, **без песочницы**. Включайте только код, которому доверяете: он получает доступ к файлам как обычная программа. Его собственные изменения не входят в undo/redo Basalgrim; **Стоп / F4** завершает процесс, но не отменяет уже выполненных им действий. Во время команды файловые операции Basalgrim не запускаются. Расширения не запускаются от root или из помощника polkit.

Сообщения и описания прокручиваются колесом, PgUp/PgDn или кнопками **Текст ↑ / ↓**. Все основные кнопки доступны при 34×14. Архивы и корзина не передаются расширениям как обычные пути.

## Рабочий пример

Установите папку [`examples/plugins/json-tools`](../examples/plugins/json-tools), затем включите **JSON**. Понадобится `/usr/bin/python3`.

- JSON-файлы получают форматированный предпросмотр.
- Команда **Проверить JSON** проверяет выбранный файл или группу, не изменяя содержимое.
- Команда **Сведения о папке** доступна для папки и свободного места.
- Последнее событие записывается в `$XDG_STATE_HOME/molten-zharr/basalgrim/json-tools/last-event.json` (по умолчанию `~/.local/state/...`).

## Формат пакета и API 1

Пакет содержит `basalgrim-plugin.json` и исполняемый файл в его корне. Допускаются обычные вспомогательные файлы и подпапки; ссылки и специальные файлы не устанавливаются. Basalgrim копирует пакет в `$XDG_DATA_HOME/molten-zharr/basalgrim/extensions/<id>`, обычно `~/.local/share/molten-zharr/basalgrim/extensions/<id>`.

```json
{
  "api": 1,
  "id": "my-plugin",
  "name": "Моё расширение",
  "version": "1.0",
  "description": "Описание возможностей",
  "executable": "main.py",
  "commands": [
    {"id": "check", "name": "Проверить", "contexts": ["file", "selection"], "extensions": ["json"]}
  ],
  "preview": ["json"],
  "events": ["directory_changed", "operation_finished"]
}
```

`commands`, `preview`, `events`, `description` и фильтр `extensions` необязательны. Контексты команды: `file` — один файл/ссылка, `directory` — одна папка, `selection` — несколько объектов, `background` — текущая папка без выбранных объектов. Фильтр проверяет расширения всех выбранных имён, без учёта регистра; в манифесте они записываются строчными буквами без точки. В `preview` выбираются только обычные файлы. Если подходят несколько поставщиков, используется первый по названию расширения.

Каждый вызов запускает отдельный процесс **без командной оболочки**. Рабочий каталог — захваченная папка. На stdin поступает один JSON, после него EOF; stdout должен содержать один JSON-ответ. Диагностика направляется на stderr. Пути передаются массивами исходных Unix-байтов; они не подставляются в команды оболочки.

`BASALGRIM_PLUGIN_DIR` указывает на установленный пакет. Храните изменяемое состояние в пользовательских XDG-каталогах, а не внутри пакета: его содержимое проверяется перед каждым запуском. Для Python выставляется `PYTHONDONTWRITEBYTECODE=1`, чтобы импорт модулей не создавал `__pycache__` в пакете.

Пример запроса (массивы ниже обозначают `/tmp` и `/tmp/a.json`):

```json
{
  "api": 1,
  "hook": "command",
  "command": "check",
  "context": {
    "cwd": [47,116,109,112],
    "selected": [{"path": [47,116,109,112,47,97,46,106,115,111,110], "directory": false, "symlink": false, "size": 2}]
  },
  "outcome": null
}
```

Ответ команды: `{"message":"Проверка завершена"}`. Ответ предпросмотра: `{"text":"Строка 1\nСтрока 2"}`. Оба поля необязательны; другие поля отклоняются. Ненулевой код выхода означает ошибку. Управляющие символы вывода экранируются для GUI/TUI.

Для предпросмотра `hook` равен `preview`, `command` — `null`, выбран один файл. Результат принимается только для действующего запроса и неизменённого файла. Это текстовый API, он не заменяет встроенные графические протоколы.

События: `directory_changed` при смене открытой папки/вкладки активной панели, `operation_finished` после результата файловой операции. Их контекст содержит текущую обычную папку и пустой выбор. `outcome` у операции содержит счётчики и признаки отмены/ошибки, например `completed=1 total=1 cancelled=false failed=false`; у перехода — `null`. События объединяются по типу и описывают последнее состояние, поэтому это **не полный журнал**. Обработчики должны быть короткими; их ошибки доступны в окне расширений и не прерывают файловые операции. Изменение одного выделения не порождает событий.

Пределы API: 32 пакета, 24 команды на пакет, 128 записей/8 MiB/8 уровней внутри пакета, манифест до 32 KiB. Выбор — до 256 объектов; запрос и stdout — до 128 KiB, stderr — до 8 KiB, `message` — до 2 KiB. Предпросмотр сохраняет до 2000 строк по 2048 символов. Время: команда 30 с, предпросмотр 3 с, событие 2 с; память процесса 512 MiB, открытые дескрипторы 128. Отмена завершает процесс и его обычную группу; намеренно отделившиеся фоновые процессы недоверенного кода этими ограничениями не изолируются.

## Локальная проверка

```sh
python3 scripts/cargo_local.py test --all-features --test extensions --test extensions_ui
python3 scripts/smoke_gui.py target/release/basalgrim --extensions-only
python3 scripts/smoke_gui_wayland.py target/release/basalgrim --extensions-only
python3 scripts/smoke_extensions.py target/release/basalgrim-tui
```

Тесты используют частные HOME/XDG, независимый исполняемый пакет и файлы. Рабочий пример и тестовые плагины не устанавливаются в пользовательский каталог автоматически.
